# Shilpi downloads

Installers and automatic updates for the Shilpi desktop app.

**[Download the latest version](https://github.com/deepuhc/shilpi-releases/releases/latest)**

- macOS: `Shilpi_<version>_aarch64.dmg` (Apple Silicon) or `Shilpi_<version>_x64.dmg` (Intel)
- Windows 10/11: `Shilpi_<version>_x64-setup.exe`

Once installed, Shilpi updates itself: a notice offers **Install and restart** when a new version is out.

This repository holds release files only.
